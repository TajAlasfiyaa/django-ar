هذه الصفحة مرجع لكتابة الدروس، وفي نفس الوقت اختبار لعرض العربية والإنجليزية معاً. إذا ظهر شيء في غير مكانه هنا، فسيظهر كذلك في الدروس.

## القواعد

- الشرح بالعربية، والكود والمصطلحات التقنية بالإنجليزية.
- اكتب الكلمات الإنجليزية كما هي، بلا أي علامات خاصة. الموقع يعزلها تلقائياً فتبقى في مكانها الصحيح.
- الكود القصير داخل الجملة بين علامتي backtick، والكود الطويل في كتلة كود.
- الأرقام بالأرقام الغربية 0 إلى 9، كما تظهر في الكود.
- علامات التنصيص العربية «هكذا»، لأنها تنعكس تلقائياً مع اتجاه الكتابة.
- اختصار لوحة المفاتيح في وسم واحد، مثل `<kbd>Ctrl+C</kbd>`، حتى لا تنعكس أجزاؤه.

## أدوات الدرس

كل الأدوات التالية مستخدمة في [نموذج الدرس الكامل](/lesson-demo/)، وملفه `src/content/docs/lesson-demo.mdx` هو أفضل نقطة بداية لأي درس جديد.

**بيانات الدرس** في أعلى الملف تصنع رأس الدرس وتذييله تلقائياً، وتجعل الدرس يُحسب في تقدّم الطالب:

```yaml
lesson:
  id: '2.4'            # رقم الدرس في المنهج
  minutes: 25          # وقت القراءة والتمارين
  objectives:          # «ماذا ستتعلم» في رأس الدرس
    - تعرف سبب مشكلة N+1.
  prerequisites: ['2.1', '2.3']   # روابط تلقائية للدروس السابقة
  docs:                # «المرجع الرسمي» في آخر الدرس
    - topics/db/fetch-modes.txt
  django: '6.1'
```

ضع ملف الدرس داخل مجلد مرحلته، مثل `src/content/docs/stage-2/`، حتى يظهر في القائمة ويُحسب في تقدّم المرحلة.

| الأداة | متى تستخدمها |
| --- | --- |
| `<Exercise>` مع `<Hint>` و`<Solution>` | تمرين، والتلميح والحل مطويّان حتى يطلبهما الطالب |
| `<Quiz answer={2}>` | سؤال سريع: السؤال، ثم قائمة الخيارات، ثم الشرح الذي يظهر بعد الإجابة الصحيحة |
| `<Summary>` | الخلاصة في آخر الدرس |
| `<Term def="...">` | مصطلح يظهر شرحه عند المرور عليه |
| `<Figure caption="...">` | شكل توضيحي يُكبَّر بالنقر |
| كتلة ` ```mermaid ` | مخطط سريع. استخدم `flowchart TD` للتسلسل الطويل |
| `showLineNumbers` و`{4}` | ترقيم الأسطر وتمييز سطر في كتلة الكود |
| `ins={3-5}` و`del={1-2}` | عرض الكود «قبل وبعد» |
| `<Tabs>` و`<FileTree>` | مقارنة بين طريقتين، وشجرة ملفات المشروع |

الأشكال المرسومة يدوياً توضع في `src/assets/diagrams/` كملفات SVG، وتستخدم أصناف `dg-` الموجودة في `src/styles/study.css` حتى تتبع الوضع الفاتح والداكن تلقائياً.

## إنجليزي داخل جمل عربية

- الإصدار القادم هو Django 6.2 LTS، ويُدعم ثلاث سنوات على الأقل.
- يحتاج Django 6.1 إلى Python 3.12+ على الأقل.
- نستخدم Django REST Framework في المرحلة 4.
- معمارية Django اسمها MTV (Model-View-Template).
- تثبّت Django بالأمر `python -m pip install django` من الطرفية.
- نجلب الوظائف المفتوحة بـ `Job.objects.filter(is_open=True)` ثم نرتبها.
- هذه جملة تنتهي بكلمة إنجليزية مثل Django.
- للتفاصيل اقرأ [Django documentation](https://docs.djangoproject.com/) الرسمية.
- آخر إصدار هو 6.1.2، وصدر في 6 أكتوبر 2026.
- اضغط <kbd>Ctrl+C</kbd> لإيقاف الخادم.

## كتلة كود

النصوص العربية داخل الكود، مثل `verbose_name`، تظهر صحيحة أيضاً:

```python title="jobs/models.py"
from django.db import models


class Job(models.Model):
    title = models.CharField("المسمى الوظيفي", max_length=200)
    company = models.ForeignKey("Company", on_delete=models.CASCADE)
    is_open = models.BooleanField("متاحة للتقديم", default=True)

    def __str__(self):
        return self.title
```

## جدول

| الأمر | ما يفعله |
| --- | --- |
| `makemigrations` | ينشئ ملف migration من تغييرات الـ models |
| `migrate` | يطبّق الـ migrations على قاعدة البيانات |
| `runserver` | يشغّل خادم التطوير على المنفذ 8000 |
