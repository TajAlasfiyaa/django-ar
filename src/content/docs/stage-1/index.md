في نهاية هذه المرحلة تكون عندك أول نسخة من منصة الوظائف: قائمة وظائف وصفحة تفاصيل، تديرها من لوحة الإدارة.

:::note[الدروس قيد الكتابة]
تظهر الدروس في القائمة الجانبية فور نشرها.
:::

| # | الدرس | ما ستتعلمه |
| --- | --- | --- |
| 1.1 | ما هو Django | معمارية MTV، ورحلة الطلب داخل Django |
| 1.2 | أول مشروع وأول تطبيق | `startproject`، `startapp`، هيكل الملفات، `runserver` |
| 1.3 | Custom User Model من البداية | خطوة جاهزة الآن، والشرح الكامل في المرحلة 2 |
| 1.4 | الـ views والـ URLs | دالة view، `path()`، المتغيرات في الرابط، `include()` |
| 1.5 | القوالب | المتغيرات، الوسوم، الفلاتر، وراثة القوالب |
| 1.6 | الملفات الثابتة | CSS والصور أثناء التطوير |
| 1.7 | أول الـ models | الحقول الأساسية، choices، `__str__` |
| 1.8 | العلاقات | `ForeignKey`، `ManyToManyField`، `OneToOneField` |
| 1.9 | الـ migrations | الإنشاء، التطبيق، التراجع، قراءة ملف migration |
| 1.10 | الـ shell وأول الاستعلامات | `all()`، `filter()`، `get()` |
| 1.11 | لوحة الإدارة | التسجيل، `list_display`، البحث، الفلاتر |
| 1.12 | أول اختبار وأدوات التشخيص | `TestCase`، صفحة الأخطاء، Django Debug Toolbar |
