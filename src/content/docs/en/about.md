A free site that teaches Django in Arabic to developers who know basic Python, from a first project to a production app.

## Who it's for

Developers who know basic Python and want to build web applications. Python itself is not re-taught, but Stage 0 covers what most beginners stumble on: how the web works, classes and inheritance, and decorators.

## What the content is based on

The reference is the official Django 6.1 documentation. Every lesson ends with the documentation file it is based on, so you can always check the source.

With each new Django release, the documentation is compared between versions, and only the lessons whose sources changed are updated.

## The project

Throughout the path you build an Arabic job board: companies post jobs and job seekers apply. Each stage adds to the same project, until you deploy it to a real server in Stage 4.

## Language

Lessons are written in Arabic. Code and technical terms stay in English, exactly as they appear in the documentation and in error messages.

## Contribute

The site is open source on [GitHub](https://github.com/TajAlasfiyaa/django-ar). Found a mistake? Use "Edit page" at the bottom of a lesson, or open an issue. To write a lesson, follow the [contributing guide](https://github.com/TajAlasfiyaa/django-ar/blob/main/CONTRIBUTING.md) (Arabic).
